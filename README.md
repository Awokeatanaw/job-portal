# 💼 Job Portal System

A modern full-stack **Job Portal Web Application** that connects **job seekers** and **employers**.  
Employers can post jobs and manage applications, while job seekers can browse jobs, save them, and apply easily.

---

## 🚀 Features

### 👤 Job Seeker
- Register and log in as a **Job Seeker**
- View available job listings
- Save jobs for later
- Apply for jobs
- View saved jobs
- View applied jobs
- Manage personal profile

### 🏢 Employer
- Register and log in as an **Employer**
- Create and manage company profile
- Post new job vacancies
- View all posted jobs
- Receive and view applications from job seekers
- See messages/details when a job seeker applies

---

## 🧩 Technologies Used

### Frontend
- **React + Vite**
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Lucide React** (Icons)

### Backend
- **Supabase**
  - Authentication (Auth)
  - Database
  - File Storage

## ⚙️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/your-username/job-portal.git
cd job-portal
```

### 2. Install dependencies
```bash
cd frontend
npm install
```
### 3. Environment Variables

Create a .env file in the frontend root:
```bash
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
### 4. Run the application
```bash
npm run dev
```
## 💻 Usage

1.Register as a Job Seeker or Employer

2.Employers can post jobs and manage applications

3.Job seekers can browse jobs, save them, and apply

4.Users can manage profiles and track activities
